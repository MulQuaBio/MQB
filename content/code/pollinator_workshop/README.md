# Pollinator watches

Open `task.html` in a browser and follow the exercises in order. Try each one
before you open the hint, candidate or worked explanation.
Open the final exercise in the last ten minutes of the workshop. If you are
working at your own pace, open it after completing Create.

Use a terminal from this folder, with Python 3 available. Use `python3` or
`py -3` in place of `python` if that is how you start Python on your computer.

```text
python code/summarise_watches.py data/pollinator_watches.csv
python checks/check_watches.py
```

Keep your coursework in a separate folder. You can run the program and
its checks with or without a coding assistant. Open `replay/` for the prepared
examples and the command output from the demonstration. Save your own
attempts separately so you can go back to the supplied data and checks.

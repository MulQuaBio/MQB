## How to use

- If you need to set up software, start with [Tooling and Environments](appendices/tooling.md).
- If an unfamiliar computing word is getting in the way, use [Key computing terms](appendices/terms.md).
- If you are new to notebooks, start with the [Jupyter / notebooks intro](notebooks/appendix-jupy-intro).
- If you want extra practice or deeper dives, pick the relevant topic appendix.
